# FTP

- file transfer protocol (FTP) is een protocol dat uitwisseling van bestanden tussen computers vergemakkelijkt. 
- het is uitgekomen in  1971 
---

## voordeelen nadelen?

voordelen:
- envoudig
- meerderen bestanden tegelijk

nadelen:

1. geen beveiliging
2. fire wall acces
3. geen encryptie

---

## SFTP

sftp is hetzelfde als FTP maar heeft well beveiliging en encryptie



## waarvoor gebruik je het
Ftp word gebruikt om van je computer bestqndend te stuuren naar een server
